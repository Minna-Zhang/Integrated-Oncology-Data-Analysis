# Integrated-Oncology-Data-Analysis
## Project Overview
Integrated Oncology Data Analysis is an independent project explore patterns in global oncology clinical development using real-world clinical trial data. The project looks at how oncology research activity differs across time, cancer types, clinical phases, geographic regions, sponsors, and therapeutic approaches. The aim is not only to describe these patterns, but also to interpret what they may suggest about broader developments in oncology research, clinical innovation, and the biotech industry.

## Project Objectives
This project aims to:
1. Identify major trends in global oncology clinical trial activity 
2. Compare clinical development across different cancer types and trial phases
3. Examine how oncology research activity is distributed across countries and regions
4. Explore differences between industry-sponsored and non-industry-sponsored trials
5. Investigate therapeutic and intervention trend where the available data allows
6. Apply appropriate data cleaning, exploratory analysis, visualization, and statistical methods
7. Interpret the findings from scientific, clinical and industry-relevant perspectives

## Research Questions
1. How has global oncology clinical trial activity changed over time?
2. Which cancer types are most heavily represented in clinical development?
3. How are oncology trials distributed across different clinical phases?
4. Which countries and regions contribute most to global oncology research activity?
5. How do industry-sponsored trials differ from non-industry-sponsored trials?
6. What broader therapeutic or development trends can be identified from the available data?

## Project outputs
The completed project will include:
1. a cleaned and structured oncology clinical trial dataset
2. exploratory analysis covering temporal, cancer-type, phase, geographic and sponsor-level patterns
3. A set of publication-style figures and visualisations
4. statistical comparisons where appropriate
5. documented Jupyter notebooks showing the full analysis process
6. a concise summary of the main scientific, clinical and industry-relevant findings.
7. A final project report outlining the data, methods, results, interpretation and limitations.

## Workflow
1. Source and review a suitable oncology clinical trial dataset
2. Select the variables most relevant to the research questions
3. Clean and standardise the raw data
4. Explore the dataset using descriptive statistics and visualisation
5. Compare patterns across time, cancer type, phase, geography, and sponsor type
6. Apply statistical tests where they add meaningful evidence
7. Interpret the results in scientific, clinical, and industry context
8. Summarise the main findings in the final report and GitHub repository
